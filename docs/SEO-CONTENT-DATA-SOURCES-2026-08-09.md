## Data boundary used on all core pages

Values apply only to the stated product grade, submitted sample and/or reported test conditions. They must be checked against the complete test method, sample configuration, substrate, thickness and operating conditions before a project decision. Values from one product form, report or substrate are not averaged or transferred to another.

## Deliberately excluded claims

- No public `UL94-V0`, 1-hour, 2-hour or other fire-resistance-duration promise.
- No customer names, project photographs, energy-saving results, certification claims, pricing or factory/manufacturer claim.
- No 2025 water-repellent values for which the supplied report records a non-standard test substrate and does not issue a standards-based determination.
